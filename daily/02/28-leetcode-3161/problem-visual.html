Add some obstacles, then run a query.

Gap ledger — what the segment tree stores

Each obstacle owns the gap to its left: gap[p] = p − (previous obstacle). Stored at the obstacle's compressed index. This is exactly the segment tree's leaf array.

How a query is answered

Answer = max(A, B) ≥ sz:

  • Part A = biggest gap between obstacles both ≤ x  →  segtree.MaxRange(0, index_of(x))
  • Part B = trailing gap x − floor(x), where floor(x) = largest obstacle ≤ x (not in the tree → computed separately)
